Kind: feature

- **Its folder says whose it is.** Paper now tells Kehikot that the paper folder in a project is its own and holds each epic's LaTeX sources, chapters and figures, so a module that shows the project's files can say what a file there is and who writes it.

## For agents

- Paper now provides the `module.folders` service: `{ name: 'Paper', folders: [{ folder: 'paper', says: …, derived: false }] }`. Read it with `services.find('module.folders')` and `foldersOwned`.
- The `document.proposals` descriptor is unchanged.
- Paper does not provide `cue.targets`: none of its tools turns its page. A walk-through turns the paper by the passage the host carries, not by a call to Paper.
